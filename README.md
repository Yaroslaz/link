# Подключение

Небольшая страница для подключения привязанного устройства к компьютеру.

Страница статическая: на ней нет ни данных, ни учётных записей. Устройство один раз привязывается к компьютеру
по одноразовому коду (QR-код или ссылка, проверка четырёх цифр на обоих экранах), после чего соединяется с ним
напрямую через WebRTC. Всё, что показывается после подключения, приходит с самого компьютера по этому соединению
и дополнительно зашифровано ключами, которые знают только привязанное устройство и компьютер.

- Для встречи устройств используются короткие зашифрованные записки: через собственную точку встречи владельца
  или, если она недоступна, через публичные ретрансляторы. Точка встречи не видит содержимого.
- Ключ устройства хранится в браузере как неизвлекаемый ключ WebCrypto.
- «Забыть это устройство» удаляет ключ из браузера; на компьютере устройство удаляется отдельно.

Файлы: `index.html`, `app.js`, `sw.js` (работа без сети и передача запросов страницы в соединение),
`manifest.webmanifest`, значки.
